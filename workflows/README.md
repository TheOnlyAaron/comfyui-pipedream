# Pipedream Workflows

Example workflows for the wedge (iteration) nodes. Each folder has a README describing the setup; `workflow.json` files will be added once PD Wedge is reworked (#3).

| # | Workflow | What it shows |
|---|----------|---------------|
| 05 | Single Wedge | One PD Wedge iterating over a prompt list; queue injection basics |
| 06 | Multi-Wedge + Rasterizer | Two wedges (prompt + seed), Rasterizer preview, cartesian product |

Both use a simple SD1.5/SDXL backbone as a placeholder.
